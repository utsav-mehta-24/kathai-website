## Overall Direction

We should treat each flavour as more than a different ingredient combination. Each one should have its own **taste profile, personality, mood, and consumption occasion**.

The flavour page should help someone quickly answer:

- What does it taste like?
- How intense/sweet is it?
- What makes it different?
- When would I drink it?
- Should I have it with milk or black?
- Which flavour fits me?

We should keep the language premium and distinctive, but still conversational enough for an 18–30 audience.
